# Export Mixdown and Stems Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add one tool, `live_export`, that exports the running song's mixdown or stems with a chosen range, formats and options. It returns (and optionally moves) the files it wrote, and leaves the user's export settings as they were.

**Architecture:**
1. A bridge op, `exportSettings`, reads, applies and restores Studio One's live export settings (`Host.Settings`).
2. A static PowerShell script presses OK in Studio One's own export dialog with a posted Enter key.
3. Node code orchestrates: validate, snapshot the folders, apply the settings, run the command and the dialog driver together, restore, diff the folders, move the files.

**Tech Stack:** Node ESM, `node:test`, zod, PowerShell 5 (Windows), and the Studio One device JS (`device/StudioOneMCP/BridgeCore.js`).

**Spec:** `docs/superpowers/specs/2026-10-07-export-design.md`

## Global Constraints

- **Device code** (`BridgeCore.js`) never throws and never touches a host member without checking it exists first (`has(obj, key, "function")`). An uncaught error, or a TypeError on a host object, pops a modal "Scripting Error" that blocks the bridge. Failures return `fail("...")`. Match the file's existing style.
- **The PowerShell script is static:** every input comes through `S1MCP_XD_*` environment variables, with no string interpolation of inputs into script text (the pattern of `scripts/preset-dialog.ps1` / `src/plugins/filedialog.js`). The script never brings a window to the front and never sends input to anything except the new export dialog or alert it found, all belonging to Studio One's process.
- **Format names:** `wav aif flac caf m4a ogg opus mp3`. The aliases are `aiff → aif` and `vorbis → ogg`.
- **Range names:** `loop` = 0, `song` = 1, `markers` = 2.
- Tests that read source files normalise CRLF (`.replace(/\r\n/g, '\n')`).
- **Commits:** the trailer is `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Stage only the task's files (never `.superpowers`), and never push.
- `npm test` stays green (470 pass at the start).

## Review Focus

1. **Restore after a failure.** If the export fails anywhere after `apply` (no dialog, an alert, a timeout, or an exception in the files step), the user's settings must still be restored. That means `exportSettings restore` runs in `finally`. Covered in Task 4 tests.
2. **Unknown format or bad options.** These must fail **before** any bridge write or command: validation happens first. Covered in Task 4 tests.
3. **Device format swap with a missing entry.** For example, the requested format is already current, or its entry is absent. This must return `fail`, never throw, and never leave a half-applied codec. The device checks the target entry exists before mutating anything. Covered in Task 1 tests.
4. **Other windows of Studio One** (the main window, a plug-in editor) must never receive keys. Only a new `CCLDialogClass` with an owner gets Enter; an alert is only handled after the export dialog has closed. Covered by Task 2 static tests.
5. **Name collisions in `output`.** Moving onto an existing file must not overwrite it; it gets a ` (2)` suffix. Covered in Task 3 tests.

**Fake attributes object** (for s1host). It mirrors the real API seen live:

```js
export function fakeAttrs(init = {}) {
  const names = Object.keys(init);
  const vals = new Map(Object.entries(init));
  return {
    getAttribute: (n) => vals.get(n),
    setAttribute: (n, v) => { if (!vals.has(n)) names.push(n); vals.set(n, v); },
    removeAttribute: (n) => { if (vals.delete(n)) names.splice(names.indexOf(n), 1); },
    countAttributes: () => names.length,
    getAttributeName: (i) => names[i],
    getAttributeValue: (i) => vals.get(names[i]),
  };
}
export const fakeFileType = (ext) => ({ extension: ext, description: `${ext} file` });
// A codec section as Studio One 7.2.3 keeps it: current trio on top, one entry per other format.
export function fakeCodec(current = 'mp3', others = ['wav', 'aif', 'flac', 'caf', 'm4a', 'ogg', 'opus']) {
  const top = { fileType: fakeFileType(current), format: { fmt: current }, attributes: fakeAttrs({ bitRate: 4 }) };
  for (const ext of others) top[ext] = fakeAttrs({ selected: 0, fileType: fakeFileType(ext), format: { fmt: ext } });
  return fakeAttrs(top);
}
```

`Host.Attributes(pairs)` in the fake builds `fakeAttrs` from the flat `[k, v, k, v…]` pairs, and keeps `.pairs = pairs`.

**Device implementation** (inside class `Bridge`; `has` and `fail` exist in the file):

```js
    // ---- export settings (Song/Export Mixdown, Song/Export Stems) ---------------
    // Host.Settings holds the live settings the export dialogs read when they open.
    // The codec section keeps the CURRENT format on top (fileType, format, attributes;
    // always exported) and one entry per other format (selected: 0/1, mixdown only).

    exportSections(kind) {
        if (kind !== "mixdown" && kind !== "stems") return null;
        const base = kind === "mixdown" ? "SongRenderer" : "StemRenderer";
        if (!Host.Settings || !has(Host.Settings, "getAttributes", "function")) return null;
        const renderer = Host.Settings.getAttributes(base);
        const codec = Host.Settings.getAttributes(base + ".AudioCodec");
        const ok = (a) => a && has(a, "getAttribute", "function") && has(a, "setAttribute", "function") && has(a, "countAttributes", "function");
        return ok(renderer) && ok(codec) ? { renderer, codec } : null;
    }

    exportExt(fileType) {
        return fileType && fileType.extension !== undefined && fileType.extension !== null ? String(fileType.extension).toLowerCase() : "";
    }

    exportEntries(codec) {
        const out = [];
        for (let i = 0; i < codec.countAttributes(); i++) {
            const name = String(codec.getAttributeName(i));
            const v = codec.getAttributeValue(i);
            if (name !== "fileType" && name !== "format" && name !== "attributes" && v && has(v, "getAttribute", "function")) out.push(name);
        }
        return out;
    }

    exportState(kind, s) {
        const opts = kind === "mixdown"
            ? ["importToTrack", "realtimeOption", "closeAfterExport", "preMasterFX", "writeAudioTempo"]
            : ["importToTrack", "realtime", "closeAfterExport", "preMasterFX", "writeAudioTempo", "splitMono", "keepSpeakerFormat"];
        const options = {};
        for (const n of opts) { const v = s.renderer.getAttribute(n); if (v !== undefined && v !== null) options[n] = Number(v); }
        const current = this.exportExt(s.codec.getAttribute("fileType"));
        const entries = this.exportEntries(s.codec);
        const selected = [current];
        if (kind === "mixdown") for (const e of entries) { if (Number(s.codec.getAttribute(e).getAttribute("selected")) === 1 && selected.indexOf(e) < 0) selected.push(e); }
        const available = [current].concat(entries.filter(e => e !== current));
        return { kind: kind, range: Number(s.renderer.getAttribute("renderRange")), current: current, selected: selected, available: available, options: options };
    }

    exportSettings(args) {
        const kind = String(args.kind || "");
        const s = this.exportSections(kind);
        if (!s) return fail("export settings are not reachable (kind must be mixdown or stems)");
        this.exportSnapshots = this.exportSnapshots || {};
        const action = args.action || "get";
        if (action === "get") return this.exportState(kind, s);
        if (action === "restore") {
            const snap = this.exportSnapshots[kind];
            if (!snap) return { restored: false, settings: this.exportState(kind, s) };
            for (const part of ["renderer", "codec"]) {
                const sec = s[part];
                const names = {};
                for (const pair of snap[part]) { names[pair[0]] = true; sec.setAttribute(pair[0], pair[1]); }
                if (has(sec, "removeAttribute", "function")) {
                    const extra = [];
                    for (let i = 0; i < sec.countAttributes(); i++) { const n = String(sec.getAttributeName(i)); if (!names[n]) extra.push(n); }
                    for (const n of extra) sec.removeAttribute(n);
                }
            }
            delete this.exportSnapshots[kind];
            return { restored: true, settings: this.exportState(kind, s) };
        }
        if (action !== "apply") return fail("action must be get, apply or restore");
        // Validate everything before changing anything.
        const formats = Array.isArray(args.formats) ? args.formats.map(f => String(f).toLowerCase()) : null;
        const current = this.exportExt(s.codec.getAttribute("fileType"));
        const entries = this.exportEntries(s.codec);
        if (formats) {
            if (!formats.length) return fail("formats is empty");
            if (kind === "stems" && formats.length !== 1) return fail("stems take exactly one format");
            for (const f of formats) if (f !== current && entries.indexOf(f) < 0) return fail("format " + f + " is not available");
        }
        if (args.range !== undefined && [0, 1, 2].indexOf(Number(args.range)) < 0) return fail("range must be 0, 1 or 2");
        // Snapshot (references) so restore puts the user's settings back exactly.
        const snapOf = (sec) => { const out = []; for (let i = 0; i < sec.countAttributes(); i++) out.push([String(sec.getAttributeName(i)), sec.getAttributeValue(i)]); return out; };
        if (!this.exportSnapshots[kind]) this.exportSnapshots[kind] = { renderer: snapOf(s.renderer), codec: snapOf(s.codec) };
        if (args.range !== undefined) s.renderer.setAttribute("renderRange", Number(args.range));
        const o = args.options || {};
        for (const n in o) if (Object.prototype.hasOwnProperty.call(o, n) && o[n] !== undefined && o[n] !== null) s.renderer.setAttribute(n, o[n] ? 1 : 0);
        s.renderer.setAttribute("closeAfterExport", 1);
        if (formats) {
            const target = formats[0];
            if (target !== current) {
                const entry = s.codec.getAttribute(target);
                const holder = Host.Attributes(["selected", 0]);
                if (!holder || !has(holder, "setAttribute", "function")) return fail("cannot create a settings entry");
                holder.setAttribute("fileType", s.codec.getAttribute("fileType"));
                holder.setAttribute("format", s.codec.getAttribute("format"));
                const attrs = s.codec.getAttribute("attributes");
                if (attrs) holder.setAttribute("attributes", attrs);
                s.codec.setAttribute(current, holder);
                s.codec.setAttribute("fileType", entry.getAttribute("fileType"));
                s.codec.setAttribute("format", entry.getAttribute("format"));
                const eAttrs = entry.getAttribute("attributes");
                if (eAttrs) s.codec.setAttribute("attributes", eAttrs);
            }
            if (kind === "mixdown") {
                for (const e of this.exportEntries(s.codec)) {
                    if (e === target) continue;
                    const ent = s.codec.getAttribute(e);
                    if (ent && has(ent, "setAttribute", "function")) ent.setAttribute("selected", formats.indexOf(e) >= 0 ? 1 : 0);
                }
            }
        }
        return this.exportState(kind, s);
    }
```

Note: `exportState`'s `available` lists the current format plus every entry. After a swap, the target's own entry still exists until Studio One normalizes it (that is fine), and `selected` must not list the target twice; the `indexOf` guard handles this.

### Task 3: Export folders and file moves (`src/export/folders.js`)

**Files:**

**Interfaces:**

  - `exportFolders(songFile, kind, { readSettingsXml = defaultReader } = {}) → string[]`:
    - the folder from `settings.xml` in the section `SongRenderer` (mixdown) or `StemRenderer` (stems): the first `url="file:///…"` inside that `<Section path="…">…</Section>`, URL-decoded and converted with `fileURLToPath`, without a trailing separator;
    - then `<dirname(songFile)>/Mixdown` or `/Stems`;

    - `defaultReader(songFile)` returns the settings.xml text or `null` on any error.
  - `snapshotFolders(folders) → Map<string, string>`: path → `${mtimeMs}:${size}`, for files directly inside existing folders whose extension is in AUDIO_EXTS.
  - `newFiles(before, after) → string[]`: paths in `after` that are missing from `before` or have a different value, sorted.
  - `moveFiles(files, output, { kind, fs = node:fs } = {}) → string[]` (the final paths):
    - **mixdown + `output` with an audio extension:**
      - requires exactly one file, whose extension equals the output's, otherwise throws `Error('output is a file path but the export wrote N files; give a folder')`;
      - otherwise creates the parent dir and moves the file there.
    - **any other `output`:** a folder, created recursively; each file keeps its name.
    - **Collision:** if the destination exists, insert ` (2)`, ` (3)`… before the extension.
    - **Move:** `renameSync`; on `EXDEV`, `copyFileSync` + `unlinkSync`.
  - `checkOutput(output, kind, formats) → void`: throws early, before any export, for stems with an output that has an audio extension (`'stems need a folder for output'`), and for mixdown file output when `formats` has more than one entry or the extension does not match `formats[0]` (when formats is given).

**Interfaces:**
- Consumes:
  - `exportSettings` (Task 1);
  - `windowsSnapshot`, `driveExportDialog` (Task 2);

  - the bridge ops `song` (returns `{ title, fileUrl, transport: { playing, recording, loopRange: { start: { seconds }, end: { seconds } } } }`) and `command`.
- Produces: `exportAudio(call, opts, deps = {}) → Promise<result>`. `deps` lets tests replace `windowsSnapshot`, `driveExportDialog`, `exportFolders`, `snapshotFolders`, `moveFiles`, `studioOnePid` (default: finds the `Studio One` process ID via `tasklist /FO CSV /NH /FI "IMAGENAME eq Studio One.exe"`, with a fallback to `Studio Pro.exe`; throws if none) and `now`.

Order of operations (exactly):

1. **Validate opts:**
   - `kind` is required;
   - `range ∈ {loop, song, markers}` → 0/1/2;
   - map `formats` through the aliases and check them against the 8 names;
   - stems need exactly one format if any are given;
   - `split_mono`/`realtime` only for stems (with a mixdown they throw "only for stems");
   - `timeout_s` must be in 10..3600, default 600;
   - `checkOutput(output, kind, formats)`.
2. `song = await call('song')`:
   - if it is playing or recording → `Error('stop playback first')`;
   - a missing `fileUrl` → `Error('save the song once first (File/Save): the export folder is next to the song file')`;
   - `range === 'loop'` (or the range is omitted and the current range, from `exportSettings get`, is 0) with `loopRange.end.seconds <= loopRange.start.seconds` → `Error('set the loop range first (live_set_loop)')`.
3. `folders = exportFolders(songFile, kind)`, then `before = snapshotFolders(folders)`.
4. `pid = await studioOnePid()` and `winBefore = await windowsSnapshot(pid)`.
5. `applied = await call('exportSettings', { kind, action: 'apply', range, formats, options })`.
   - The options map is `{ importToTrack: import_to_track, preMasterFX: skip_master_fx, writeAudioTempo: write_tempo, realtime, splitMono: split_mono }`, keeping only defined ones.
6. Inside `try`, start both of these, and do not await the first before starting the second:
   - `cmd = call('command', { category: 'Song', name: kind === 'mixdown' ? 'Export Mixdown' : 'Export Stems' }, { timeoutMs: timeout_s*1000 })`;
   - `drive = driveExportDialog({ pid, before: winBefore })`.
   - Then `const d = await drive`.
     - If `!d.ok`, await the command with a catch, and throw `Error` with reason-specific text:
       - no dialog: `Studio One did not open the export dialog`;
       - alert: `Studio One refused the export ("<title>"): check the range (loop/markers) and formats`;
       - otherwise: `export dialog: <reason>`.
     - Else `await cmd`.
   - In `finally`: `call('exportSettings', { kind, action: 'restore' })`. If it rejects, set the warning `could not restore your export settings: <msg>`.
7. `after = snapshotFolders(folders)`, then `files = newFiles(before, after)`.
   - If there are none → `Error('the export ran but no new files were found in: <folders joined>; if you changed the location in the dialog without saving the song, look there')`.
8. If `output`: `files = moveFiles(files, output, { kind })`.
9. Return `{ kind, range: <name from applied.range>, formats: applied.selected, files: files.map(p => ({ path: p, bytes: fs.statSync(p).size })), seconds: (now()-t0)/1000, settingsRestored: <bool>, ...(warning ? { note: warning } : {}) }`.
